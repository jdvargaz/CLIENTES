Panorama General del Sitio

Victorias Rápidas (Quick Wins)

Acciones de bajo esfuerzo y alto impacto para implementar esta semana:

1. Añadir Meta Descripciones

La web actualmente carece de ellas[cite: 3]. Añadir textos persuasivos mejorará los clics desde Google en un 15-20% casi de inmediato.

2. Optimizar Imágenes Estrella

Reducir el peso de imágenes como Colageno-gotas.png (842 KiB) y ASTAXANTIN.jpg (795 KiB)[cite: 1] ahorrará más de 2 MB en la carga móvil, bajando drásticamente el rebote.

3. Agregar Atributos ALT

Faltan 10 etiquetas ALT en imágenes[cite: 3]. Agregarlas permitirá posicionar el catálogo en Google Imágenes (tráfico gratuito).

Tiempos de Carga (Core Web Vitals)

El tiempo de carga visual (LCP) en móviles es de 14.6 segundos[cite: 1], lo cual penaliza severamente el SEO y la conversión.

Peso de la Web por Recursos

La página carga 3.14 MB (3,145 KiB) en total[cite: 1]. Las imágenes representan el mayor problema y la mejor oportunidad de ahorro (2,052 KiB estimables)[cite: 1].

Ajustes de Estructura Web (DOM y CMS)

El análisis técnico arroja que la estructura construida con Elementor está afectando el rendimiento. El Document Object Model (DOM) es el código que el navegador debe leer.

Exceso de Profundidad en el Diseño (DOM)

La web tiene un total de 846 elementos HTML, lo cual es aceptable, pero cuenta con una profundidad máxima de 21 niveles generados por contenedores anidados de Elementor (ej. div.elementor-container > div.elementor-widget)[cite: 1, 2].

Solución: Utilizar los nuevos "Flexbox Containers" de Elementor para reducir las columnas internas innecesarias y aligerar el cálculo de la página.

Limpieza de CSS y JS

La web está cargando ~14.5 KiB de CSS sin usar[cite: 1]. Múltiples librerías de WordPress que no aplican a la página principal se están descargando.

Solución: Instalar un plugin de optimización (ej. WP Rocket o LiteSpeed Cache) para combinar y minificar el CSS, retrasando el JavaScript que no es crítico para el primer pantallazo visual.

Ecosistema de Medición y Analítica Digital

Actualmente la web necesita integrar herramientas formales de seguimiento para medir el tráfico real, identificar el origen de los compradores y optimizar la pauta publicitaria en WooCommerce sin perder datos por bloqueo de cookies.

Google Search Console (GSC)

Propósito: Monitorear la indexación, subir el Sitemap XML oficial y conocer las palabras clave exactas con las que la gente llega a GreenLab en Google.

Indispensable para SEO

Google Analytics 4 (GA4)

Propósito: Medir el comportamiento de usuarios, embudos de conversión e ingresos de WooCommerce (añadidos al carrito, compras completadas y tasa de rebote).

Medición de Ventas

Google Tag Manager (GTM)

Propósito: Centralizar todos los códigos de seguimiento en un solo lugar. Evita tocar el código PHP de la web cada vez que se agrega una nueva etiqueta.

Píxeles de Publicidad (Ads)

Meta Pixel + Conversions API (CAPI)

Meta Ads (Facebook & Instagram): Permite crear campañas de Retargeting para personas que vieron productos como Cannabis Sativa o Fibras pero no compraron. La API de Conversiones es vital para medir compras desde el servidor respetando las restricciones de iOS/Safari.

TikTok Ads Pixel

TikTok Ads: Ideal para campañas dinámicas de video de suplementos y bebidas funcionales dirigidas a audiencias jóvenes. Mide eventos como ViewContent, AddToCart y Purchase en WooCommerce.
